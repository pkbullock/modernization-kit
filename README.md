# PnP Modernization and Page Transformation Toolkit

The purpose of the kit is to provide those considering a modernisation project, the tools, process and resources to run a conversion project.

---

## Plan for a simple process

- identify
- plan
- modernise
- review
- publish

## Identify

- Process
	- Gather sites and usage data

- Technical
	- SharePoint List with Pages within a site
	- Directory to rollout status to a master tenant list
	- Create Modernisation Page Tracking List
	- Script for tenant tracking of usage of Classic Page Usage

## Plan

- Process
	- Collect Classic Sites
	- Collect Transform Candidate Pages within Sites
	- Design the target layouts e.g. News, Landing, Content
	- Project Team - Template
	- Determine in and out of scope rules
		- Age Content e.g. Too Old
		- Folder and Subsite Exclusion
	
- User Adoption
	- Notification Banner for Site Modernisation
	- Site Template for Central Adoption 
	- Communication Templates for staff notification
	
- Technical
	- Copilot Component to report and allow users to provide status updates
	- Status report on a site
	- Status report on the estate for stakeholder reporting

## Modernise

- Process
	- Convert the page
	- Check for errors in the output, adjust an instance of the page layout mapping if necessary.

- Technical
	- Conversion Mapping Files
	- Conversion
	- Conversion Logs

## Review

- Assign Reviewers
- Log Issues
- Approval

## Publish

- Process
	- Using the list, find the page and ensure it is Published.
- Technical
	- Script: Using the "Complete status of the list", publish the page on the new location
