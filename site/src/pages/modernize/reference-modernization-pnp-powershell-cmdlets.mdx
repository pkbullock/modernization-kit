## PnP Page Transformation Related Cmdlets

The following cmdlets are commonly used in the Page Modernization workflow with PnP Powershell:

- `Get-PnPPage`: Retrieves information about a modern page.
- `Set-PnPPage`: Updates properties or layout of a modern page.
- `Remove-PnPPage`: Deletes a modern page.
- `Add-PnPPageSection`: Adds a section to a modern page.
- `Add-PnPPageWebPart`: Adds a web part to a modern page section.
- `Connect-PnPOnline`: Connects to a SharePoint Online site using PnP PowerShell.
- `Disconnect-PnPOnline`: Disconnects the current PnP PowerShell session from the SharePoint Online site.


### `ConvertTo-PnPPage`: Converts a classic page to a modern page.

```powershell
# Example usage of ConvertTo-PnPPage
ConvertTo-PnPPage [-Identity] <ClassicPagePipeBind> `
    [-Library <String>] `
    [-Folder <String>] `
    [-WebPartMappingFile <String>] `
    [-Overwrite] `
    [-TakeSourcePageName] `
    [-ReplaceHomePageWithDefault] `
    [-AddPageAcceptBanner] `
    [-SkipItemLevelPermissionCopyToClientSidePage] `
    [-SkipUrlRewriting] `
    [-SkipDefaultUrlRewriting] `
    [-UrlMappingFile <String>] `
    [-ClearCache] `
    [-CopyPageMetadata] `
    [-AddTableListImageAsImageWebPart] `
    [-UseCommunityScriptEditor] `
    [-SummaryLinksToHtml] `
    [-TargetWebUrl <String>] `
    [-LogType <PageTransformatorLogType>] `
    [-LogFolder <String>] `
    [-LogSkipFlush] `
    [-LogVerbose] `
    [-DontPublish] `
    [-KeepPageCreationModificationInformation] `
    [-SetAuthorInPageHeader] `
    [-PostAsNews] `
    [-DisablePageComments] `
    [-PublishingPage] `
    [-BlogPage] `
    [-PageLayoutMapping <String>] `
    [-PublishingTargetPageName <String>] `
    [-TargetPageName <String>] `
    [-TargetPageFolder <String>] `
    [-TargetPageFolderOverridesDefaultFolder] `
    [-RemoveEmptySectionsAndColumns] `
    [-TargetConnection <PnPConnection>] `
    [-SkipUserMapping] `
    [-UserMappingFile <String>] `
    [-TermMappingFile <String>] `
    [-SkipTermStoreMapping] `
    [-SkipHiddenWebParts] `
    [-Connection <PnPConnection>]

```
Reference: [ConvertTo-PnPPage | PnP PowerShell Documentation](https://pnp.github.io/powershell/cmdlets/ConvertTo-PnPPage.html)

Some commands are not recommended to be used as they may relate to deprecated modernization scenarios or have limited support in newer versions of the Page Modernization tools. These include:

- [-LDAPConnectionString]
- [-DelveBlogPage] 
- [-DelveKeepSubTitle]
- [-ClassicBlogPage]

These may be removed in future versions of PnP PowerShell.


## `Save-PnPPageConversionLog` 

The `Save-PnPPageConversionLog` cmdlet is used to save the conversion log of a page transformation operation.

```powershell
# Example usage of Save-PnPPageConversionLog
Save-PnPPageConversionLog [-Identity] <ClassicPagePipeBind> `
    [-LogType <PageTransformatorLogType>] `
    [-LogFolder <String>] `
    [-Connection <PnPConnection>]
```

Reference: [Save-PnPPageConversionLog | PnP PowerShell Documentation](https://pnp.github.io/powershell/cmdlets/Save-PnPPageConversionLog.html)

## `Export-PnPPageMapping`

The `Export-PnPPageMapping` cmdlet is used to export the page mapping configuration to a file.

```powershell
# Example usage of Export-PnPPageMapping
Export-PnPPageMapping [-MappingFile <String>] `
    [-Connection <PnPConnection>]
```

Reference: [Export-PnPPageMapping | PnP PowerShell Documentation](https://pnp.github.io/powershell/cmdlets/Export-PnPPageMapping.html)
