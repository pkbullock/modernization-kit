## Deprecated Modernization Scenarios

Over the course of time, Microsoft have deprecated certain modernization scenarios in the Page Modernization workflow. These scenarios are no longer recommended for use and may not be supported in future updates.

### On-Premises to SharePoint Online Modernization

On-Premises for example, SharePoint 2010,2013,2016,2019 and SharePoint Subscription Editions to SharePoint Online within community scenarios are no longer supported and not receiving updates in newer versions of the Page Modernization tools.
You can continue to use older versions of the Page Modernization tools for example PnP PowerShell version 1.x, but be aware that these versions may not receive updates or support for newer SharePoint Online features.

[PnP.PowerShell Module (v1.12) | PowerShell Gallery](https://www.powershellgallery.com/packages/PnP.PowerShell/1.12.0) contains support for On-Premises versions of Transformation.


## Delve Blogs

The modernization tooling supported Delve Blog to Modern Page transformation but the Delve service is now retired and no longer recommended for use.


## Classic Blog

The modernization tooling supported Classic Blog to Modern Page transformation but the Classic Blog service is now creation restricted and no longer recommended for use.
